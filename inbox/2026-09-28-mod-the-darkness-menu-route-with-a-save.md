# The Darkness (rexglue PC port): menu route once a save exists

Profile: `profiles/the-darkness.json`. Found by the `/lm` session on 2026-09-28, home PC.

- **Once a save exists, the route changes** `[verified-live 2026-09-28, n=4]`. There is no
  "No Gamer Profile" dialogue any more. The main menu opens on CONTINUE.
- **Working route:** at about 52 s after launch press **START**, then **A** (the save-icon notice).
  Then press **A** on CONTINUE. The opening car scene is up 25-40 s later. Pad route: ViGEm X360
  (vgamepad), with the window foregrounded before each press.
- **Disproved with a save present:** the older `START A DOWN A WAIT A ...` route. DOWN moves to NEW
  GAME, which now asks "Starting a new game will delete all your saves. Are you sure?". The cursor
  starts on NO, so the stray A presses were harmless. **Hazard: a DOWN then A there deletes the
  saves.** `[verified-live 2026-09-28, n=2]`
- The car scene loaded via CONTINUE opens still and fading in. Use it for static measurements, not
  for anything that needs motion.
